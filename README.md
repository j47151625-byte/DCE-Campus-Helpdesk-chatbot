# DCE Campus Help Desk Chatbot

A no-code AI chatbot built on Botpress that answers questions about
Dhanalakshmi College of Engineering: programmes, admissions, campus
information and career support, in English or Tamil.

## Live Demo
https://cdn.botpress.cloud/webchat/v5.0/shareable.html?configUrl=https://files.bpcontent.cloud/2026/10/19/06/20261019060349-OFI11WTU.json

## Features
- Answers from the college's official website content
- English and Tamil support
- Shows the source used for each answer
- Available 24/7 through a web link

## Tech Used
- Botpress (no-code AI agent platform)
- Botpress Knowledge Base
- Botpress Webchat
